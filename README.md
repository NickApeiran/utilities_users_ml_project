# utilities_users_ml_project

Machine learning project developed as part of the Big Blue Academy Data Science / Machine Learning bootcamp.

Project members

Nikolaos Apeiranthitis, Alexandros Tetsinis, Stavros Lefakis, Alexandros Papalexandris

Project Overview

This project analysis and attempts to cluster anonymized energy-utilities customer using unsupervised methods

The workflow includes:

data cleaning
exploratory data analysis
clustering with two algorithms (kmeans and dbscan)
and final presentation
